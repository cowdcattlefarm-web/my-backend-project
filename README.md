# Dairy Farm Management API

FastAPI backend for dairy farm animals, animal events, milk entries, income, expenses, dashboard summaries, and financial reports.

## Stack

- FastAPI
- PostgreSQL
- SQLAlchemy ORM
- Alembic
- Pydantic v2
- Supabase JWT auth for write APIs

## API Docs

After starting the app:

- Swagger UI: `http://127.0.0.1:8000/docs`
- ReDoc: `http://127.0.0.1:8000/redoc`
- OpenAPI JSON: `http://127.0.0.1:8000/openapi.json`
- Health check: `http://127.0.0.1:8000/api/v1/health/`

All routes are registered under `/api/v1`.

## Setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Update `.env` with your PostgreSQL and Supabase settings.

## Local Run Command

```powershell
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

## Migration Commands

Apply existing migrations:

```powershell
alembic upgrade head
```

Create a new autogenerated migration after model changes:

```powershell
alembic revision --autogenerate -m "describe change"
```

Check migration chain:

```powershell
alembic heads
alembic history --verbose
```

## Environment Variables

Required:

- `DATABASE_URL`: PostgreSQL URL, for example `postgresql+psycopg://user:password@host:5432/dbname`
- `SUPABASE_URL`: Supabase project URL, for example `https://your-project-ref.supabase.co`
- `SUPABASE_JWT_AUDIENCE`: usually `authenticated`

Recommended:

- `APP_NAME`: API title shown in Swagger
- `APP_ENV`: `development`, `staging`, or `production`
- `APP_HOST`: local host, default `127.0.0.1`
- `APP_PORT`: local port, default `8000`
- `API_V1_PREFIX`: default `/api/v1`
- `CORS_ORIGINS`: comma-separated frontend origins
- `TIMEZONE`: default `Asia/Kolkata`
- `CURRENCY`: default `INR`

Optional auth overrides:

- `SUPABASE_JWKS_URL`: defaults to `<SUPABASE_URL>/auth/v1/.well-known/jwks.json`
- `SUPABASE_JWT_SECRET`: legacy HS256 fallback

## Auth

Write APIs require a Supabase bearer token:

```http
Authorization: Bearer <supabase-access-token>
```

Current write APIs are `POST`, `PUT`, and `DELETE`. Read APIs are public.

## Main Routes

- `GET /api/v1/health/`
- `GET|POST /api/v1/animals`
- `GET|PUT|DELETE /api/v1/animals/{animal_id}`
- `GET|POST /api/v1/animals/{animal_id}/events`
- `GET /api/v1/animal-events`
- `GET|PUT|DELETE /api/v1/animal-events/{event_id}`
- `GET|POST /api/v1/milk-entries`
- `GET|PUT|DELETE /api/v1/milk-entries/{milk_entry_id}`
- `GET /api/v1/milk-entries/daily-summary`
- `GET /api/v1/milk-entries/monthly-summary`
- `GET /api/v1/milk-entries/animal/{animal_id}/summary`
- `GET|POST /api/v1/income`
- `GET|PUT|DELETE /api/v1/income/{income_id}`
- `GET|POST /api/v1/expenses`
- `GET|PUT|DELETE /api/v1/expenses/{expense_id}`
- `GET /api/v1/dashboard/summary`
- `GET /api/v1/dashboard/milk-trend`
- `GET /api/v1/dashboard/financial-summary`
- `GET /api/v1/dashboard/upcoming-events`
- `GET /api/v1/dashboard/alerts`
- `GET /api/v1/financials/summary`
- `GET /api/v1/financials/profit-loss`
- `GET /api/v1/financials/category-summary`
